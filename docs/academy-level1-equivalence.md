# JDL Core Academy Level 1 course scope

The client brief is an equivalent **learning experience** to the 85-page SGS OGC Level 1 Training Handbook, written as an original JDL course. Equivalent means that a learner can explain and apply every technical topic in the source outline, complete worked exercises, and pass questions specific to each skill. Matching headings alone does not meet the brief. The SGS employee-only wording, proprietary procedures, illustrations and tables must not be copied.

Source outline: https://online.flippingbook.com/view/230683251/

Technical reference points for review: [API measurement standards catalogue](https://www.api.org/products-and-services/standards/standards-plan), [API MPMS 17.6 description of line-fullness methods](https://www.api.org/~/media/files/publications/whats%20new/17_6%20e2%20pa.pdf), [OSHA Safety Data Sheet requirements](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.1200AppD), and [OSHA hydrogen sulfide exposure guidance](https://www.osha.gov/hydrogen-sulfide/evaluating-controlling-exposure). ## Acceptance criteria

1. Every subsection above has its own explanation, limitations, worked field example or decision exercise, and assessment questions.
2. Practical procedures identify the applicable current standard and JDL-approved operating procedure; numerical tolerances and hazardous-entry instructions require competent review before publication.
3. Calculation lessons contain at least one fully worked shore-tank and marine-tank example with raw data, units, intermediate quantities, correction references and reconciliation.
4. A technical reviewer checks the material for safety and calculation accuracy, and a JDL operations owner approves it as company training.
5. The live learner page displays the expanded content and questions; the seed preserves existing progress, attempts and certificates.

The 12-session course contains extended teaching, fictional cases, a glossary and conversion exercise, worked shore- and marine-tank chains based on explicitly fictional table outputs, and 60 lesson-specific questions. It is displayed as the normal Academy course. This document is an internal coverage checklist for the client's evaluation; the learner-facing content does not mention that process. No JDL-approved operating methods or tank tables were supplied. The configured database was inaccessible from this workspace, so the course has not yet been loaded there.
